# 우리동네 3GO 행정 자동화 & 공공데이터 연동 스킬

## 지침 (Instructions)

1. **AI 4-Way 홍보문 원클릭 생성 (`src/modules/admin-ai/`)**
   - 입력: 행사명, 일시, 장소, 대상, 핵심 내용.
   - 출력 탭 4개:
     1. 아파트 엘리베이터 공고문
     2. 언론 보도자료 초안
     3. 주민 안내 문자/SNS 글
     4. 1080×1080 카드뉴스 프리뷰 (Canvas 이미지 저장)
   - Gemini 무료 티어 API(`GEMINI_API_KEY`)를 호출하되, API 키 미설정 시 완성도 높은 사전 템플릿 스트리밍 시뮬레이션으로 동작하게 한다.

2. **공개 품의 폼 ➔ 에듀파인/e호조 엑셀(.xlsx) 자동 변환**
   - `xlsx` (SheetJS) 라이브러리를 사용해 `budget_proposals` 데이터를 공공 회계 표준 컬럼(`품목명`, `규격`, `수량`, `단가`, `금액`, `산출기초`, `구매처링크`, `비고`)으로 시트를 구성해 즉시 `.xlsx` 파일로 다운로드시킨다.

3. **인앱 안심 톡방 회의록 PDF 변환**
   - `chat_messages`의 대화 로그를 AI로 `[회의 개요 / 주요 결정사항 / 예산 및 역할 분담 / 다음 일정]` 4단 구조로 요약하고, `jspdf` + `html2canvas` 또는 인쇄용 레이아웃으로 공식 회의록 PDF를 출력한다.

4. **공공데이터 6대 API 어댑터 (`src/lib/public-data.ts`)**
   - 대상 6종:
     1. 광주광역시 도시공원정보 표준데이터
     2. 광주광역시 생활안전지도·보안등·CCTV
     3. 소상공인시장진흥공단 상가(상권)정보 (원정대 보급소)
     4. 광주광역시 소방서·옥내소화전·대피소
     5. 한국사회보장정보원 노인일자리·복지시설
     6. 기상청 단기예보 및 미세먼지(에어코리아)
   - 모든 호출 함수는 `try-catch` + 3초 타임아웃을 적용하고, 실패 시 `src/data/fallback-public-data.json`을 반환하며 UI에 `[실시간 API 연동]` 또는 `[시연용 스냅샷 모드]` 배지를 작게 표시한다.
